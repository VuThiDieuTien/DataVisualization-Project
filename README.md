# ABC Supermarket Data Analysis & Visualization

## Overview
This project analyzes supermarket transaction data to uncover sales trends, customer purchasing behavior, and branch performance. The project focuses on data visualization, dashboard development, and business insight generation.

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Power BI

## Key Contributions
- Performed exploratory data analysis (EDA) on supermarket transaction data.
- Created diverse visualizations including bar charts, line charts, heatmaps, scatter plots, and violin plots.
- Selected appropriate chart types based on data characteristics and analytical objectives.
- Applied data storytelling techniques to support business decision-making.

## Results
- Identified sales trends across branches.
- Analyzed customer behavior and purchasing patterns.
- Generated recommendations for customer segmentation and business strategy optimization.
